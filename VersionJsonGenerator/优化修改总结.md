### 1. MD5计算流未释放修复
**文件**: 
- `VersionJsonGenerator\Form1.cs` 第204-212行
- `Updater\Form1.cs` 第305-313行

**问题**: MD5计算时打开的文件流未释放，导致资源泄漏和文件锁定

**修改前**:
```csharp
static string GetFileMD5(string filePath)
{
    var md5 = System.Security.Cryptography.MD5.Create();
    var stream = File.OpenRead(filePath);
    byte[] hash = md5.ComputeHash(stream);
    return BitConverter.ToString(hash).Replace("-", "").ToLower();
    // stream 未释放！
}
```

**修改后**:
```csharp
static string GetFileMD5(string filePath)
{
    using (var md5 = System.Security.Cryptography.MD5.Create())
    using (var stream = File.OpenRead(filePath))
    {
        byte[] hash = md5.ComputeHash(stream);
        return BitConverter.ToString(hash).Replace("-", "").ToLower();
    }
}
```

### 5. 添加下载重试机制
**文件**: `Updater\Form1.cs` 新增方法

**新增功能**: 支持失败自动重试，可配置重试次数

```csharp
/// <summary>
/// 带重试机制的下载方法
/// </summary>
private async Task<bool> DownloadWithRetryAsync(FileItem fileItem, string localFilePath, 
    CancellationToken token, int maxRetries = 3)
{
    for (int retry = 0; retry < maxRetries; retry++)
    {
        try
        {
            if (retry > 0)
            {
                Log($"重试下载 ({retry}/{maxRetries})：{fileItem.path}");
                await Task.Delay(1000, token);
            }
            
            var resp = await _httpClient.GetAsync(fileItem.url, ...);
            // ... 下载逻辑
            return true;
        }
        catch (OperationCanceledException)
        {
            throw; // 取消操作，向上抛出
        }
        catch (Exception ex)
        {
            Log($"下载失败：{ex.Message}");
            if (retry == maxRetries - 1)
                return false;
        }
    }
    return false;
}
```

### 8. 版本号格式验证
**文件**: `VersionJsonGenerator\Form1.cs`

**新增功能**: 验证版本号格式

```csharp
/// <summary>
/// 验证版本号格式（x.x.x 或 x.x）
/// </summary>
private bool IsValidVersion(string version)
{
    if (string.IsNullOrWhiteSpace(version)) return false;
    var parts = version.Split('.');
    if (parts.Length < 2 || parts.Length > 4) return false;
    foreach (var part in parts)
    {
        if (!int.TryParse(part, out int num) || num < 0)
            return false;
    }
    return true;
}

// 在 btnGenerate_Click 中使用
if (!IsValidVersion(newVer))
{
    MessageBox.Show(this, "版本号格式错误！\n正确格式：x.x.x（如 1.0.0）");
    return;
}
```
