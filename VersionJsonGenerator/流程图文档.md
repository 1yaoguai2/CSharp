## 2. 服务端版本生成流程

```mermaid
flowchart TD
    Start([开始]) --> A[打开VersionJsonGenerator]
    A --> B[选择发布根目录]
    B --> C{目录存在?}
    
    C -->|否| D[提示错误]
    D --> B
    
    C -->|是| E[设置服务器基础地址]
    E --> F[设置端口号]
    F --> G[点击"读取"按钮]
    
    G --> H{version.json存在?}
    H -->|是| I[读取旧版本号]
    H -->|否| J[设置为0.0.0]
    
    I --> K[自动递增版本号]
    J --> K
    
    K --> L[点击"版本生成"按钮]
    L --> M[清空文件列表]
    M --> N[递归扫描目录]
    
    N --> O{遍历每个文件}
    O --> P{在黑名单中?}
    
    P -->|是| O
    P -->|否| Q[添加到扫描列表]
    Q --> O
    
    O -->|扫描完成| R[遍历扫描列表]
    R --> S[计算文件MD5]
    S --> T[构建FileItem对象]
    T --> U{还有文件?}
    
    U -->|是| R
    U -->|否| V[序列化为JSON]
    V --> W[写入version.json]
    W --> X[显示完成提示]
    
    X --> End([生成完成])
```

## 3. HTTP服务启动流程

```mermaid
flowchart TD
    Start([开始]) --> A[点击"启动Http服务"按钮]
    A --> B{发布目录存在?}
    
    B -->|否| C[提示选择目录]
    C --> End([结束])
    
    B -->|是| D{端口格式正确?}
    D -->|否| E[提示端口错误]
    E --> End
    
    D -->|是| F{服务已运行?}
    F -->|是| G[提示已运行]
    G --> End
    
    F -->|否| H[创建HttpListener]
    H --> I[添加URL前缀]
    I --> J[启动监听]
    J --> K[获取本机IP]
    K --> L[更新服务器地址显示]
    L --> M[启动后台任务]
    
    M --> N[等待请求]
    N --> O{收到请求}
    
    O --> P[解析请求路径]
    P --> Q{文件存在?}
    
    Q -->|否| R[返回404]
    R --> N
    
    Q -->|是| S[读取文件内容]
    S --> T[返回文件数据]
    T --> N
    
    N -.可被停止.-> U[点击"停止Http服务"]
    U --> V[停止监听]
    V --> W[关闭连接]
    W --> End
```

## 6. 文件更新流程

```mermaid
flowchart TD
    Start([点击更新按钮]) --> A{游戏运行中?}
    
    A -->|是| B[StopGameProcess]
    A -->|否| C[禁用所有按钮]
    
    B --> B1[获取进程列表]
    B1 --> B2[遍历进程]
    B2 --> B3[Kill进程]
    B3 --> B4[等待进程退出]
    B4 --> C
    
    C --> D[清空进度显示]
    D --> E[获取游戏目录路径]
    E --> F[创建HttpClient]
    F --> G[遍历远程文件列表]
    
    G --> H{本地文件存在?}
    H -->|否| I[添加到下载列表]
    H -->|是| J[计算本地MD5]
    
    J --> K{MD5匹配?}
    K -->|是| L[记录跳过日志]
    K -->|否| I
    
    L --> M{还有文件?}
    I --> M
    M -->|是| G
    
    M -->|否| N{下载列表为空?}
    N -->|是| O[提示已是最新]
    N -->|否| P[开始下载循环]
    
    P --> Q[获取文件项]
    Q --> R[构建本地路径]
    R --> S{目录存在?}
    
    S -->|否| T[创建目录]
    S -->|是| U[发送HTTP GET请求]
    T --> U
    
    U --> V[获取响应流]
    V --> W[创建文件流]
    W --> X[异步读取写入]
    X --> Y[关闭所有流]
    Y --> Z[释放资源]
    
    Z --> AA[延时释放文件锁]
    AA --> AB[计算下载文件MD5]
    AB --> AC{MD5匹配?}
    
    AC -->|否| AD[删除损坏文件]
    AD --> AE[抛出异常]
    
    AC -->|是| AF[更新进度显示]
    AF --> AG{还有文件?}
    
    AG -->|是| P
    AG -->|否| AH[显示完成提示]
    AH --> AI[隐藏更新控件]
    AI --> AJ[恢复按钮状态]
    AJ --> End([更新完成])
    
    AE --> End
    O --> End
```

## 11. 时序图：完整更新流程

```mermaid
sequenceDiagram
    autonumber
    participant User as 用户
    participant VG as VersionJsonGenerator
    participant HTTP as HTTP Server
    participant UP as Updater
    participant FS1 as 服务端文件系统
    participant FS2 as 客户端文件系统
    participant Game as 游戏进程
    
    rect rgb(200, 220, 240)
        Note over User,FS1: === 服务端准备阶段 ===
        User->>VG: 选择发布目录
        VG->>FS1: 扫描文件
        FS1-->>VG: 文件列表
        VG->>FS1: 计算每个文件MD5
        VG->>FS1: 写入version.json
        User->>VG: 点击启动HTTP服务
        VG->>HTTP: 启动监听
    end
    
    rect rgb(220, 240, 200)
        Note over User,Game: === 客户端更新阶段 ===
        User->>UP: 启动Updater
        UP->>FS2: 加载配置和图片
        UP->>HTTP: GET /version.json
        HTTP-->>UP: 返回JSON
        UP->>UP: 解析版本信息
        UP->>FS2: 检查本地文件MD5
        UP->>UP: 生成下载列表
        
        opt 有文件需要更新
            UP->>UP: 显示更新按钮
            User->>UP: 点击更新
            UP->>Game: 检测并关闭游戏进程
            Game-->>UP: 进程已关闭
            
            loop 每个需要下载的文件
                UP->>HTTP: GET /path/to/file
                HTTP->>FS1: 读取文件
                FS1-->>HTTP: 文件数据
                HTTP-->>UP: 文件字节流
                UP->>FS2: 写入文件
                UP->>FS2: 验证MD5
            end
            
            UP->>User: 提示更新完成
        end
        
        User->>UP: 点击启动游戏
        UP->>FS2: 检查游戏exe
        UP->>Game: Process.Start
        UP->>UP: 关闭Updater
    end
```

## 12. 状态转换图

```mermaid
stateDiagram-v2
    [*] --> 待检测: 启动Updater
    
    待检测 --> 检测中: 开始版本检测
    检测中 --> 无更新: 所有文件MD5匹配
    检测中 --> 有更新: 存在差异文件
    检测中 --> 检测失败: 网络错误
    
    检测失败 --> 待检测: 重试
    
    无更新 --> 游戏就绪: 隐藏更新按钮
    有更新 --> 等待更新: 显示更新按钮
    
    等待更新 --> 更新中: 用户点击更新
    更新中 --> 下载文件: 开始下载
    下载文件 --> 校验MD5: 文件下载完成
    校验MD5 --> 下载文件: MD5不匹配
    校验MD5 --> 更新完成: 所有文件校验通过
    更新中 --> 更新失败: 下载错误
    
    更新失败 --> 等待更新: 显示错误
    
    更新完成 --> 游戏就绪: 隐藏更新按钮
    
    游戏就绪 --> [*]: 用户启动游戏
```
